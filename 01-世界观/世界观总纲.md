# 世界观总纲

## 一句话概念

近未来的沿海城市爆发不明传染事件后，一名急救员与一群互不信任的幸存者，试图带着一支不断变化的队伍穿过被海潮和感染者切割的江岬市，在安全区承诺失效之前，找到能让普通人长期活下去的地方。

## 故事定位

- **工作名**：《潮线以北》
- **类型**：丧尸生存、灾后群像、社区建设
- **主要舞台**：虚构沿海城市“江岬市”
- **时代**：近未来，科技与当下相近；不依赖科幻装备解决危机
- **基调**：紧张、克制、现实；保留互助与希望，但不保证所有人都能幸存
- **核心问题**：资源有限时，谁有权决定谁值得被救？活下来之后，人们要共同遵守什么？

## 故事前提

江岬市连续遭遇高温与强降雨，港区一处冷链仓储事故后出现不明高热、意识混乱和攻击行为。最初，官方将事件判断为局部治安与医疗危机；数日内，急诊、交通枢纽和老城区相继失守，通讯与供电开始分区中断。

故事从疫情失控后的第六天开始。主角林土二原是急救员，在一次转运失败后与同伴失散。她收到弟弟林知远发出的短讯，称自己在北岸潮汐观测站附近；与此同时，城内广播反复播报一个正在撤离的“北堤安置点”。两条线索都可能过时，也都可能是陷阱。

## 时间线

以“失控日”作为计时起点。

| 时间 | 事件 |
|---|---|
| 失控日前约两周 | 港区冷链仓储区出现来源不明的发热病例；病例被分散送医，尚未形成公开警报。 |
| 失控日（D0） | 多家医院同时接诊高热、意识障碍和攻击性病例；城市应急响应启动。 |
| D1—D2 | 急诊与交通枢纽拥堵；局部断电，通信开始不稳定；官方信息前后不一。 |
| D3—D5 | 港区、老城和城际客运站出现大规模伤亡；部分行政单位撤离，街区自救组织形成。 |
| D6 | 正篇开始。林土二收到弟弟的短讯，决定前往北岸。 |
| D7—D14 | 主角团穿过数个城区，发现安置点已分裂成不同的幸存者组织。 |
| D15—D30 | 队伍由临时同行转为共同生活；供水、冲突与冬季前的迁移成为主要压力。 |
| D30以后 | 故事进入重建阶段：生存据点扩张，旧秩序残余与新规则发生冲突。 |

## 感染概念

- 工作名：**灰潮感染**。这是幸存者的俗称，不代表病原体颜色或官方命名。
- 病原体性质与最初来源在故事中不立即定论；港区冷链事故是调查线索，不直接等同于最终答案。
- 传播以感染者的血液、唾液进入伤口或黏膜为主。普通社交距离下的空气传播不成立。
- 感染者死亡后可再次活动；详细阶段、限制和辨识方式见[感染与生存规则](./感染与生存规则.md)。
- 不设置可轻易获得的万能疫苗或即时解药。医疗知识能提高存活率，但不能取代隔离、护理和艰难决策。

## 世界运行原则

1. **危机有因果**：声音、光线、天气、地形和体力都会改变行动结果。
2. **资源有限但可计算**：食物、水、药物、燃料、弹药与睡眠都有明确消耗。
3. **制度不是瞬间消失**：广播、基层人员、仓库与应急流程会以残缺、冲突或局部形式继续存在。
4. **人群不是单一阵营**：组织内部有分歧；敌对者也有可理解的动机。
5. **胜利不是清空地图**：阶段性目标是降低风险、建立可信规则、让更多人获得选择。

## 主题与冲突

- **主要主题**：互助与控制之间的界线；信任如何在危机中建立；照护者的责任是否有边界。
- **外部冲突**：感染者、洪水与潮汐、基础设施失效、资源争夺、撤离信息不可靠。
- **内部冲突**：主角习惯把“救人”当作个人责任；队伍必须决定何时冒险、何时止损。
- **长期悬念**：感染的源头、安置点撤离失败的真实经过、弟弟为何隐瞒自己掌握的信息。

## 不采用的设定

- 感染者不会突然进化出超自然能力。
- 不以“所有政府人员都邪恶”作为默认前提。
- 不让主角团凭空获得无限弹药、万能车辆或不受限制的医疗资源。
- 不把感染者仅作为战斗数量；每次冲突都应影响资源、关系或后续选择。
