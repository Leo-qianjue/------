- 先定规则：阅读世界观总纲与感染规则。
- 先定人物：阅读核心人物与关系。
- 开始拆分情节：阅读全书大纲，并随写作调整。
- 正文存放位置：`05-正文/`（当前为空）。

## 设定变更约定

1. 涉及感染规则、时间线或人物生死的修改，应同步检查相关文档。
2. 尚未决定的内容标记为“待定”，不要在正文中提前当作确定事实。
3. 已写入正文的事实优先级高于未落地的规划；若要推翻，先记录原因并统一修订。
