# 核心人物与关系

> 人物年龄与背景为工作设定，可在正式拆章前微调。姓名暂定。

## 人物关系总览

```text
林土二 ──姐弟 / 失联与隐瞒── 林知远
   │                              │
   ├──救援搭档、理念冲突── 周野   └──掌握港区事故线索
   │
   ├──医护伙伴、互相质疑── 许宁
   │
   └──信任与旧怨交织────── 陈望

主角团 ──暂时合作 / 资源竞争── “北堤安置点”管理组

主角团 ──路线与物资冲突────── 港区搬运队
```

## 主要人物

### 林土二

- **年龄 / 身份**：29岁；前急救员，擅长现场评估、止血和组织转运。
- **表层目标**：找到弟弟林知远，并带同行者抵达安全地点。
- **深层需求**：接受个人能力与责任都有边界，不再把每次失败都归咎于自己。
- **优势**：冷静、执行力强、能迅速建立行动优先级。
- **弱点**：容易越过团队共识擅自承担风险；不愿透露自己曾放弃一次转运。
- **关系弧线**：从“必须救下每一个人”转向“与他人共同决定怎样救、由谁承担代价”。
- **不可轻易改变的事实**：她不是医生，无法独立完成复杂诊疗；救援判断也可能出错。

### 林知远

- **年龄 / 身份**：23岁；通信设备维护学徒，失控前在港区外包团队工作。
- **表层目标**：躲避港区冲突，前往北岸观测站。
- **隐瞒事项**：他知道冷链仓储区曾有异常转运记录，但并不掌握完整真相。
- **优势**：熟悉无线电、线路与城市边缘道路。
- **弱点**：遇到压力时倾向于独自行动，并用半真半假的信息保护姐姐。
- **关系弧线**：从被寻找的目标，转变为能够承担选择后果的独立行动者。
- **剧情功能**：连接家庭情感、港区线索与通讯网络；不能成为解开所有谜团的万能钥匙。

### 周野

- **年龄 / 身份**：35岁；前市政水务维修工，曾参与河西社区防灾演练。
- **表层目标**：把同行者带到可长期供水的地点。
- **深层需求**：从“只有我知道正确做法”转向授权与共享技术。
- **优势**：熟悉水泵、管线、地形和基础设施维修。
- **弱点**：习惯把经验当成命令；对官方机构积怨深，容易误判他人动机。
- **关系弧线**：与林土二从互相挑战决定权，发展为分工明确的共同领导。

### 许宁

- **年龄 / 身份**：31岁；社区诊所护士，长期照护慢性病患者。
- **表层目标**：确保队伍中伤病者与慢性病患者不被抛下。
- **优势**：护理、药物管理、安抚与观察。
- **弱点**：可能为了照顾眼前病人而低估全队风险；对“放弃救援”尤其敏感。
- **关系弧线**：由强调个体照护，逐步参与建立可持续的公共医疗规则。
- **剧情边界**：护士技能不等于诊断、手术或无限药品。

### 陈望

- **年龄 / 身份**：42岁；运输车队调度员，早年曾参与一次事故后的物资转运。
- **表层目标**：用路线、车辆与交易维持自己的小队生存。
- **隐瞒事项**：他曾把一批应送往旧城医院的物资改道，导致林土二失去一次救援机会；当时的决策背景并不简单。
- **优势**：判断路线和人群风险，熟悉物流与车辆调度。
- **弱点**：把信息当筹码，倾向先谈交易再谈信任。
- **关系弧线**：从交易型合作者到愿意公开承担旧决定后果的人。
- **戏剧功能**：让主角面对不完全的责任归属，而不是提供简单的赎罪答案。

## 关系变化节点

| 阶段 | 关系变化 |
|---|---|
| 初遇 | 林土二与周野因撤离路线和救援优先级冲突；许宁坚持带走伤者；陈望只肯提供有偿协助。 |
| 临时同行 | 一次夜间转移失败后，众人开始交换真实资源与技能，但仍保留个人信息。 |
| 信任破裂 | 林土二发现陈望与旧城物资转运有关；队伍分裂为追责、利用他的路线能力和立即分道三派。 |
| 共同决策 | 面对社区据点的供水危机，队伍建立公开的配给与表决规则。 |
| 后期关系 | 林土二与林知远重逢后不再默认替他做决定；主角团由依附关系转为互相负责的伙伴关系。 |

## 人物写作约束

- 每位主要人物至少有一项不可替代的技能和一项会造成真实代价的局限。
- 关系变化必须由行动、选择或信息揭露推动，不靠突然和解。
- 人物的过去只在影响当下选择时揭示，不用档案式长段落替代剧情。
